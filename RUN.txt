Terminal 1 — backend (FastAPI)

  cd <path-to>/VEXA-main
  .venv/bin/python -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000

  (Use "python -m uvicorn" rather than the uvicorn script: if the .venv was created in a
   different folder, its console scripts point at the old path.)

Terminal 2 — frontend (React/Vite)

  cd <path-to>/VEXA-main/frontend
  npm install
  npm run dev          # http://localhost:5173

The Google ADK Verifier (A2A) starts automatically inside the backend on 127.0.0.1:8101.
Only if you set VEXA_A2A_EMBEDDED=false, run it yourself in a third terminal:

  VEXA_A2A_TOKEN=<secret> .venv/bin/python -m backend.a2a_bridge.verifier_server --port 8101

Tests

  .venv/bin/python -m pytest -q
